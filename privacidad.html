Política de privacidad

Última revisión: 10 de octubre de 2026. En comprimeme procuramos ofrecer herramientas útiles sin recopilar el contenido de los archivos que seleccionas para su compresión.

Archivos seleccionados

Los archivos se leen y transforman mediante JavaScript ejecutado en tu navegador. No hemos implementado un servicio o formulario para enviar esos archivos a nuestros servidores durante la compresión. Los resultados se crean como objetos temporales en el navegador y se descargan a tu dispositivo. Cuando limpias la lista o abandonas la página, se liberan las URL temporales.

Bibliotecas de terceros

La página carga bibliotecas para PDF y ZIP desde cdnjs, una red de distribución de código de terceros. El navegador realiza solicitudes para obtener ese software, lo que puede exponer a dicho proveedor datos técnicos de la conexión. Estas bibliotecas se usan para trabajar con archivos localmente y no están diseñadas en esta web para enviar el contenido de tus documentos a ese proveedor.

Alojamiento web y seguridad

La página está preparada para publicarse en Cloudflare Pages. Cloudflare puede procesar direcciones IP, datos del navegador y registros técnicos para entregar contenido y proteger el servicio, de acuerdo con sus políticas. Asimismo, tu navegador, sistema operativo, antivirus y extensiones pueden gestionar información según sus configuraciones.

Google AdSense y publicidad

El sitio incorpora el script oficial de Google AdSense, una metaetiqueta de identificación y un archivo ads.txt correspondiente al editor ca-pub-6521969406386261. Esto prepara la verificación, pero no implica que Google haya aprobado el sitio o que esté mostrando anuncios. El código de Google puede recopilar información técnica, utilizar cookies u otros identificadores conforme a las políticas publicitarias de Google.

Cuando sea necesario, deben aplicarse opciones de consentimiento y aviso adecuados a las regiones desde las que se acceda, antes de activar anuncios personalizados. La configuración publicitaria puede variar según permisos, políticas y decisiones de Google.
