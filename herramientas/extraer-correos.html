✉️ Extraer direcciones de correo de un texto

Localiza direcciones con apariencia de correo dentro de un texto y elimina repeticiones.

Prueba con tu texto

Puedes modificar el ejemplo. Máximo 50 000 caracteres por cuadro.

Resultado

Cómo funciona

El sistema busca patrones habituales con una parte local, el símbolo @ y un dominio con punto. Normaliza la comparación a minúsculas para descartar duplicados de una misma dirección y conserva el primer formato encontrado.

Ejemplo de uso

Puedes revisar una nota que hayas escrito tú mismo y extraer los correos que contiene. Después usa el botón Copiar para mover la lista a tu libreta o gestor de contactos autorizado.

Qué debes revisar

Esto no verifica que una cuenta exista, que acepte mensajes ni que sea correcto contactar a una persona. No lo uses para crear listas de envío sin consentimiento. No se transmite el texto a nuestro servidor para extraer datos.

Preguntas frecuentes

¿Necesito iniciar sesión?

No. La herramienta funciona localmente en el navegador y no guarda los textos en nuestra base de datos. No necesitas registrarte ni dar una contraseña.

¿Puedo usarla para un trabajo escolar o laboral?

Sí, para transformar o examinar tus propios escritos. Revisa el resultado antes de entregarlo, especialmente si hay nombres propios, instrucciones particulares o información privada. Estas utilidades no reemplazan la edición humana.

También puedes usar

  • Quitar líneas duplicadas
  • Ordenar listas alfabéticamente
  • Convertidor de texto a listas
Tu privacidad: los textos no se envían a un servidor propio para procesarse. Evita pegar información confidencial innecesaria.
