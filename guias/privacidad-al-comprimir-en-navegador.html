¿Se suben los archivos? Qué significa comprimir localmente

Cómo funciona el procesamiento en el navegador y sus límites de privacidad.

Subir un documento a un sitio de terceros y procesarlo directamente en el navegador son operaciones diferentes. En el primer caso el archivo se transmite a un servidor para ejecutar una transformación. En el segundo, el navegador recibe el programa y realiza el cálculo con los recursos de tu dispositivo.

Qué hace este proyecto

ComprimeFácil MX utiliza JavaScript del navegador para abrir, modificar y crear los archivos resultantes. No incluye una ruta de carga de documentos a nuestro servidor. Los resultados se ofrecen mediante enlaces temporales generados localmente, y se liberan al limpiar la lista o salir de la página.

¿Significa que nadie más procesa información?

No necesariamente. El sitio se aloja en Cloudflare, que puede procesar direcciones IP y datos técnicos de solicitudes. Algunas bibliotecas se descargan de un proveedor de distribución de código, y el sitio contiene código de Google AdSense. Esos terceros podrían procesar información técnica según sus respectivas políticas, aunque las herramientas no estén diseñadas para enviarles el contenido de los archivos elegidos.

Qué ocurre con el portapapeles y los archivos descargados

La descarga final queda en la carpeta que elijas o que configure el navegador. El sistema operativo, antivirus, extensiones o mecanismos de sincronización propios del equipo pueden gestionar esa copia. Limpiar una lista dentro de la web no borra un archivo ya descargado.

Precauciones con documentos sensibles

Evita tratar archivos que contengan contraseñas, datos bancarios completos o documentos ajenos sin autorización. Si tienes un equipo compartido o un entorno laboral regulado, comprueba las políticas de privacidad y seguridad antes de utilizar un servicio público.

Recomendación: para probar el compresor por primera vez usa un archivo sin información privada. Comprueba que funciona correctamente en tu navegador y que el formato de salida es aceptado.

Transparencia
