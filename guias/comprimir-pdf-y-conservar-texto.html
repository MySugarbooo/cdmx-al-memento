PDF más ligero: conservar texto o convertir páginas a imagen

Ventajas, desventajas y consecuencias de dos maneras de optimizar documentos PDF.

Un documento PDF puede incluir texto, fotografías, fuentes incrustadas, gráficos, formularios, enlaces y otros objetos. Por eso no existe un botón universal que siempre lo reduzca mucho y conserve todas sus propiedades. El método depende de lo que realmente contiene.

Optimización básica sin aplanar

Una biblioteca puede cargar un PDF y guardarlo nuevamente con una estructura de objetos distinta. En algunos casos se reduce el tamaño; en otros puede aumentar. Este modo conserva la naturaleza del PDF como documento en lugar de convertir las páginas en simples fotografías, y es el primer intento recomendado si necesitas seleccionar texto, copiar datos o usar enlaces.

Compresión fuerte por páginas rasterizadas

El segundo modo dibuja cada página en un lienzo y crea un nuevo PDF con imágenes JPEG. Puede ser útil cuando el documento es un escaneo muy pesado, pero el texto deja de ser seleccionable y los enlaces y formularios dejan de funcionar. También podrían alterarse detalles de color, firmas y anotaciones. Nunca uses este modo sobre un contrato o trámite donde deban conservarse características digitales específicas.

Cómo elegir

Si un profesor, oficina o plataforma necesita un PDF legible y con texto copiable, empieza con la optimización básica. Si vas a compartir un escaneo informal para consulta visual y nadie necesita extraer el texto, el modo de páginas como imágenes podría reducirlo más. Conserva siempre el original.

Qué ocurre con los archivos protegidos

Los PDF cifrados o dañados pueden fallar al abrirse. No se intenta eliminar contraseñas o restricciones de acceso. Si el archivo está protegido legítimamente, solicita al propietario una versión adecuada para comprimir.

Ejemplo: un PDF exportado desde un editor de texto suele ser compacto, mientras que un escaneo a resolución muy alta puede tener mayor potencial de reducción. Un PDF de una sola página no es necesariamente más pequeño que uno de diez páginas.

Comprueba después de guardar

Abre el archivo resultante y revisa todas las páginas, letras pequeñas y gráficos. Si el resultado no fue menor que el original, la herramienta lo indicará. Comprimir PDF.
