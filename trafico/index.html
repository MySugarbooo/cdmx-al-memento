Antes de tomar una ruta

  1. Comprueba si el aviso corresponde a hoy.
  2. Confirma si es un evento previsto o una afectación reportada.
  3. Revisa calle, tramo y sentido en OVIAL.
  4. Consulta la autoridad nuevamente antes de desplazarte.

Una noticia puede seguir apareciendo aunque la circulación ya se haya restablecido. El reloj de esta página indica cuándo se consultaron los titulares, no cuándo se produjo o terminó el cierre.
