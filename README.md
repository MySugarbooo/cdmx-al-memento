# TextoClaro MX

Tercera web independiente de CDMX AL MEMENTO y Cuenta y Listo MX.
10 herramientas de texto interactivas, 8 guías originales, páginas de contacto, privacidad, términos y sobre nosotros.

## Proyecto y publicación
- Repositorio conectado: `MySugarbooo/cdmx-al-memento`.
- Rama exclusiva de este sitio: `texto-claro`. **No elegir `main` ni `cuenta-y-listo`**.
- La rama `main` corresponde a CDMX AL MEMENTO; la rama `cuenta-y-listo` a la segunda página.
- Cloudflare Pages: crear proyecto nuevo conectado a este mismo repositorio, nombre sugerido `textoclaro-mx` si está disponible.
- **Production branch:** `texto-claro`.
- Framework preset: `None`.
- Build command: vacío.
- Build output directory: `.` (un punto).
- Root directory: raíz (valor predeterminado).
- Verificar que el despliegue termine correctamente y visitar la URL asignada por Cloudflare.
- El sitemap fue preparado para `textoclaro-mx.pages.dev`. Cambiarlo si Cloudflare asigna otra dirección.
