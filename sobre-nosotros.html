CAT · LAS ESTRELLAS PERDIDAS

Sobre el juego

Cat y las Estrellas Perdidas es un juego gratuito, original e independiente de plataformas que funciona directamente en el navegador. Presenta a Cat como protagonista: una joven inventora de cabello castaño largo, sombrero negro y un dispositivo de energía llamado Pulso Aurora, Lunaria. El proyecto reúne una historia propia, dieciséis niveles, una banda sonora generada por el navegador y un sistema para conservar el avance localmente.

Por qué creamos este juego

Queríamos una aventura sencilla de aprender que no exigiera cuentas, contraseñas ni instalaciones. Se puede correr, saltar dos veces, disparar luz, cargar un superpulso, esquivar ataques, enfrentar jefes, recoger destellos y atravesar portales. El objetivo es disfrutar el progreso gradual y conocer cuatro regiones que acompañan la historia.

Personaje e historia originales

Cat descubre que las máquinas del Núcleo de Medianoche robaron las estrellas de Lunaria. Para rescatar a Lira, la guardiana desaparecida, recorre el Bosque de los Circuitos Dormidos, las Torres del Viento Quieto, las Minas de Cristal Silencioso y la Fortaleza del Último Amanecer. La aventura habla de valentía, tecnología al servicio de los demás y la responsabilidad de ayudar incluso cuando el camino es difícil.

Cómo está construido

El juego utiliza Canvas y JavaScript sin un motor remoto. Los sonidos se generan con la API Web Audio, sin descargar pistas comerciales. La partida se almacena mediante localStorage en el navegador del jugador. La nueva versión incorpora disparos de energía, esquiva, cuatro jefes y una banda sonora ambiental de acordes suaves. No existe una cuenta de usuario ni una base de datos de partidas. Los mundos se dibujan con gráficos sencillos creados para este proyecto.

Publicidad y gratuidad

El sitio incorpora los preparativos de Google AdSense, pero la presencia de código publicitario no significa que Google haya aprobado mostrar anuncios. Cuando haya publicidad, seguirá sin ser necesario pulsarla para progresar. Los botones del juego no están conectados a anuncios.

Comentarios y errores

Queremos que Cat resulte divertida, clara y fácil de usar en celular y computadora. Puedes reportar errores de controles, guardado o visualización a sanchezaxochitl@gmail.com. Evita enviar información privada o contraseñas.
